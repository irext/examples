# IRext Examples

This repository contains example for application developers using IRext.

Please refer to the README.md in each of the sub-directories for detail.

- android-example: Android APP example showing how to index, download and decode IR remote binaries, can work together with Arduino example.
- android-compose-example: Android APP example using jetpack-compose.
- arduino-example: Arduino UNO R4 example with local decoding flow.
- java-example: Java server example showing how to index, download and decode IR remote binaries.
- win32-example: Windows local decode example.
